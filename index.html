Where your text
actually goes.

Four steps, one network hop you control. Read the privacy policy for the full detail.

  • 01

    You click Summarize

    Nothing is sent while you browse. The extension only acts when you ask it to.

  • 02

    Text is extracted locally

    A content script pulls the visible text in your browser. PDFs and Docs are fetched by the Worker instead.

  • 03

    The Worker calls Gemini

    Our Cloudflare Worker attaches the API key and forwards the request to Google's Gemini API.

  • 04

    Results land in the popup

    Bullets, answers and quizzes come straight back. Nothing is written to a database.

Questions,
answered.

What does summeriser. actually do?

It extracts the text of the page you're on and sends it to our Cloudflare Worker, which calls Google's Gemini API to produce bullet-point summaries, answers and quizzes.

Which model does it use?

Gemini Flash Lite, chosen for speed and a large context window. A secondary provider is configured as failover if Google is unavailable.

Where does the API key live?

As an encrypted secret on the Cloudflare Worker. It is never bundled into the extension and never sent to your browser.

Is my page content private?

We keep no database of it. But the text is processed by Google, and on the free Gemini tier Google may use submitted content to improve its services. Don't summarise contracts, medical records or anything under an NDA. The privacy policy spells this out in full.

What can it read?

Articles, PDFs, YouTube transcripts, Reddit threads, Substack posts and most ordinary web pages. Google Docs need to be shared as "anyone with the link can view".

Does it work on paywalled pages?

It reads whatever is already rendered in your tab. If you can see it, so can the extension. It does not bypass anything.
